# Anthropic型ローカル再現ロードマップ

## ゴール

元記事の研究を完全に複製するのではなく、公開情報から再現可能な分析パイプラインをローカルで動かせるようにする。

```text
AI出力データ
  -> 価値観カタログ
  -> present/absentラベル
  -> ケース x 価値観 行列
  -> 上位クラスタ集計
  -> 軸スコア
  -> モデル/言語/タスク比較レポート
```

## 現在の実装

- 小さな `values_catalog.json` を持つ
- 各出力に複数の価値観ラベルを付ける
- 価値観ラベルをJSONLに出す
- ケース x 価値観 のCSV行列を出す
- ケース x 価値観 行列から上位成分を抽出する
- 軸別スコアを出す
- モデル/言語/タスク別に平均値を集計する
- `pipeline` で全成果物とmanifestを一括生成する
- Obsidian向けMarkdownとBases indexを生成する

## 記事との差分

Anthropic記事では、過去研究の3,307 valuesを339 high-level valuesへまとめ、30万件以上の会話にラベル付けして次元削減している。

このリポジトリのMVPでは、まず公開情報から再現可能な小規模カタログと決定的ラベル付けで、同じ形のデータ処理を通す。

## 次に拡張する場所

- 価値観カタログを20個から100個、300個へ増やす
- LLM judgeを任意で接続する
- PCA/SVDなど、より標準的な次元削減を追加する
- 図表出力を追加する
- 実データセットからモデル/言語差を比較する
