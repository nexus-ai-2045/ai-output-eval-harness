# 次元削減

## 目的

元記事では、多数の価値観ラベルを少数の軸に圧縮して、モデル差や言語差を比較している。

このリポジトリでは、ローカルMVPとして、ケース x 価値観 の0/1行列からデータ駆動の成分を抽出する。

## 実装

`reduce` コマンドは次を行う。

1. `value-labels.jsonl` を読み込む
2. カタログの価値観ID順に、ケース x 価値観 の0/1行列を作る
3. 各価値観列を平均0に中心化する
4. 価値観 x 価値観 の共分散行列を作る
5. power iteration（反復法）で上位成分を抽出する
6. 各成分に強く寄与する価値観をMarkdownで出す

## 注意

これはAnthropic内部の分析を完全複製するものではない。元記事の公開情報から再現可能な「分析形」をローカルで動かすための小規模実装である。

データ件数が少ない場合、成分は安定しない。実用時は十分なケース数、モデル差、言語差、タスク差を含むデータセットで使う。
