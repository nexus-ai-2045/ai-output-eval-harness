# 公開前チェック

この文書は、`ai-output-eval-harness` を公開する前に確認する技術項目をまとめたものです。公開先のアカウント、組織内台帳、承認履歴は公開リポジトリへ含めません。

## 自動確認

- `python -m pytest`
- `python .repo-operating-contracts\check.py`
- actionlintによるGitHub Actions設定の検査
- wheelのビルドと隔離環境へのインストール
- パッケージの編集可能形式でのインストール
- wheelから導入したCLIとサンプル入力を使った簡易動作確認
- 機密情報スキャナーによる現在のファイルと全コミット履歴の検査
- 個人環境パス検査
- 依存関係の脆弱性検査
- GitHub Actionsの実行結果
- `reports/` とローカル生成物がGit管理対象外であること

## 人間による確認

- READMEとコマンド例が初めての利用者にも理解できる
- サンプルデータが合成データまたは再配布可能なデータだけで構成されている
- 価値観カタログの出典・制約・ルールベース判定の限界が説明されている
- コミット履歴に個人メール、内部パス、非公開情報がない
- GitHubのみで配布するか、パッケージレジストリにも配布するか決定済み

## GitHub設定

- Security Advisoriesと非公開脆弱性報告
- 依存関係アラート
- 既定ブランチとブランチ保護
- pull requestのレビューとCI成功を必須にする規則
- リリースタグの命名と切り戻し方法

公開操作は、自動検査と人間確認の両方が完了し、対象リポジトリと正確な操作について明示承認を得た後に行います。
