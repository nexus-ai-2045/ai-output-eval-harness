# v0.1.0 リリースノート

`ai-output-eval-harness`の最初のコアMVPです。

## 主な機能

- 1行1ケースのJSONL入力
- 期待値との一致率、根拠にない出力、低confidence項目の評価
- ケース別JSONLとMarkdown集計の生成
- 価値観ラベルとケース × 価値観CSV行列の生成
- CSV数式注入とMarkdown構造注入への対策
- 最小入力検証

## 任意機能

- 実験的な価値観比較と成分抽出
- Obsidian向けMarkdown出力

Obsidianはコア評価には不要です。

## インストール

```powershell
git clone https://github.com/nexus-ai-2045/ai-output-eval-harness.git
cd ai-output-eval-harness
python -m pip install -e .
```

## 最短実行

```powershell
python -m ai_output_eval run --input examples/sample-output.jsonl --out reports/eval.jsonl
python -m ai_output_eval summarize --input reports/eval.jsonl --out reports/summary.md
```

## 既知の制約

- 入力サイズとネスト深度に固定上限はありません。
- 価値観ラベルは小規模なルールベースカタログによる実験機能です。
- LLM評価器や正解ラベルデータセットは含みません。
- PyPIでは配布していません。
